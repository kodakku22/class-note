# FAQ / トラブルシューティング

アプリ内でも `Ctrl+K` → 「FAQ」で検索可能です。

---

## セットアップ

### Windows にインストールする方法は？
リリースページから Setup.exe または Portable.exe をダウンロードしてください。Setup 版はインストーラ付き、Portable 版はフォルダ内完結で持ち運び可能です。

### 初回起動時に何をすればいいですか？
オンボーディングウィザードが案内します。Vault フォルダを選択し、AI プロバイダを設定すれば準備完了です。

### Vault とは？新しく作る方法は？
Vault はノートやデータを保存するフォルダです。任意の空フォルダを選択するか、既存の Obsidian Vault を指定できます。

### Obsidian の Vault をそのまま使えますか？
はい。ClassNotes は Obsidian と同じフォルダ構造に対応しています。.obsidian フォルダは無視され、Wikilink 記法も共有されます。

### Portable 版と Setup 版の違いは？
Setup 版はスタートメニューに登録され自動更新対応。Portable 版は USB 等に入れて持ち運べます。機能は同一です。

### アプリを更新するには？
最新版を上書きインストール（Setup 版）するか、Portable EXE を差し替えてください。Vault データはアプリ外にあるため影響しません。

## AI 機能

### AI プロバイダはどう選べばいいですか？
Settings → AI から OpenAI (GPT-4o)、Google (Gemini)、Anthropic (Claude) を選択できます。

### API キーの設定方法は？
左上の AI セレクタ、または Settings → AI → 「API キーを設定」から入力します。キーは OS の暗号化ストレージに安全に保存されます。

### API キーが拒否されます
選択プロバイダの管理画面でキーが有効か確認してください。期限切れや使用上限に達している場合があります。

### CLI が見つかりませんと表示されます
「ログイン」モードでは各プロバイダの CLI ツールが必要です。Claude → `claude` CLI、Codex → `codex` CLI をインストールし PATH に通してください。

### AI 応答がタイムアウトします
ネットワーク接続を確認してください。Wiki コンパイルの場合はスコープを科目単位に絞ると改善します。

### AI 機能をオフにしたい
Settings → AI → プロバイダを「なし」に設定すると AI 関連機能はすべて無効になります。

### トークン上限エラーが出ます
ノートが長すぎる場合に発生します。ノートを分割するか、要約対象の範囲を選択して実行してください。

### 使用するモデルは変更できますか？
Settings → AI → 「モデル」から選択できます。速度重視なら軽量モデル、品質重視なら最新モデルを選んでください。

## Vault / データ

### Vault が表示されない / 消えた
Settings → Vault → 「最近使った Vault」から再選択してください。

### 検索や Backlinks が古い情報を表示する
Settings → Vault インデックス → 「インデックスを再構築」を実行してください。

### バックアップとリストアの方法は？
Settings → データ保護 → 「バックアップを作成」で zip バックアップが作られます。詳細は [operations.md](operations.md) を参照。

### ノートが消えてしまった
削除操作はソフトデリート（.trash フォルダへ移動）です。Vault フォルダ直下の .trash を確認してください。

### 大規模な Vault でも使えますか？
数千ファイルまでは問題なく動作します。node_modules や .git フォルダは自動的に除外されます。

## パフォーマンス

### 起動が遅い
Vault のファイル数が多い場合、初回インデックス構築に時間がかかります。2回目以降はキャッシュにより高速化されます。

### Wiki コンパイルが 5 分でタイムアウトする
スコープを「すべて」から特定の科目に絞ってください。

### メモリ使用量が多い
PDF ビューアや Mermaid 図を多用するとメモリが増加します。使わないタブを閉じると改善します。

### 起動後に挙動が不安定
Settings → 診断 → 「診断レポートを書き出す」を実行し、レポート内容を確認してください。

## エディタ

### 対応している Markdown 記法は？
GFM (GitHub Flavored Markdown) に対応。見出し、リスト、テーブル、コードブロック、数式 (KaTeX)、Mermaid 図、Wikilink、タグが使えます。

### 画像を埋め込むには？
エディタに画像ファイルをドラッグ＆ドロップするか、`![[filename.png]]` 記法で参照します。

### Wikilink が解決されない（灰色のまま）
リンク先のファイルが存在しない場合に灰色表示になります。ファイル名を確認するかインデックスを再構築してください。

## 同期 / ファイル監視

### 外部で編集したファイルが反映されない
Settings → Vault インデックス → 「インデックスを再構築」で解消します。ネットワークドライブでは監視が不安定な場合があります。

### 編集コンフリクトが発生した
ClassNotes で開いているファイルを外部ツールで同時編集すると mtime コンフリクトが検出されます。「外部の変更を読み込む」か「現在の内容を保持」を選んでください。

## DocAI (Acrobat AI 互換機能)

### Q: DocAI とは何ですか?

PDF やノートに対して AI に質問・要約・複数文書比較・コンテンツ生成ができる機能群です。Adobe Acrobat AI Assistant の主要機能 5 種に相当します:

| # | 機能 | 入口 |
|---|---|---|
| 1 | PDF 要約 | ⚡ 要約 / 📝 試験対策 / 📌 1行要約 |
| 2 | 文書 Q&A | 入力欄に質問を入れて送信 |
| 3 | 引用元リンク | 回答内の `[1]` バッジをクリック |
| 4 | 複数文書比較 | 📎+ で文書追加 → 📊 比較 |
| 5 | コンテンツ生成 | ✉ 生成 → メール/発表原稿/レポート/メモ |

### Q: DocAI の要約が遅いです。

要約は AI プロバイダーに依存します。デフォルトのタイムアウトは 90 秒です。

- **Anthropic Claude (API キー)**: 通常 5〜15 秒。大型 PDF は 30 秒超。
- **Claude Code CLI (ログイン方式)**: subprocess 起動のオーバーヘッドで +5〜10 秒。
- **OpenAI / Gemini API**: 同程度。

待機時間を改善するには:
- 小さな PDF (50 ページ以下) を使う
- 「📌 1行要約」モードを選ぶ (短い出力)
- Settings → AI Provider で高速モデル (gpt-5.4-mini / claude-haiku-4-5 / gemini-3-flash-preview) を選ぶ

### Q: 出典バッジ `[1]` が「missing」と表示されます。

AI が回答内で参照した出典番号 N が、retriever が抽出したチャンク数を超えています。原因の多くは AI のハルシネーション (実在しない出典の捏造)。

対処:
- 質問を具体的にする (「第3章の結論」のように章を指定)
- 文書を小さくする (50 ページ以下推奨)
- プロンプトのルール 1「コンテキストにない情報は『見つかりません』と回答」を強化する余地あり (将来改善予定)

### Q: 複数文書モードで何ファイルまで選べますか?

デフォルト **最大 5 文書** です (MultiDocPicker の `maxSelectable`)。Anthropic 32K 入力に対し、各文書から最大 4500 字 × 5 ≈ 22K の余裕を持たせた設定です。Wave 2+ では Settings で 3〜8 文書まで調整可能にする予定。

### Q: スキャン PDF (画像のみ) で要約が「ファイル形式エラー」になります。

`extractPdfTextFromBuffer` がテキストを取り出せませんでした。対処:

1. **API キー方式に切り替える**: Settings → AI Provider で OpenAI / Gemini / Claude (API キー) を選択。これらは Vision モデルでスキャン PDF を直接読めます (将来の Wave 3 で自動切替を実装予定)。
2. **OCR 済み PDF を用意する**: Acrobat や ABBYY などで OCR を実行してから取り込む。
3. **PDF → Markdown 化**: コマンドパレットの「PDFをMarkdown化」を実行してテキスト化されたノートを生成。

### Q: DocAI のログはどこに保存されますか?

`<vault>/.classnotes/docai/log.md` に質問・回答・出典が時系列で追記されます。誤って大量に質問してしまった場合や、後から振り返りたい場合はこのファイルを確認してください。

### Q: DocAI が大きい PDF (>50MB) を拒否します。

メモリ枯渇を防ぐためのガードです。Settings → 設定ファイル (`settings.json`) の `docaiMaxFileSizeMB` を 1〜500 で調整できます (デフォルト 50)。GUI からの変更は次リリース対応予定。
