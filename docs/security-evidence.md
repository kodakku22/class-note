# Security Evidence

ClassNotes keeps security evidence executable. The goal is not to replace a
third-party audit, but to make the audit boundary easy to inspect and repeat.

## Commands

```bash
npm run security:sbom
npm run security:ipc-surface
npm run security:evidence
```

Outputs:

- `security/sbom.cdx.json` — CycloneDX-style dependency inventory generated
  from `package-lock.json`.
- `security/ipc-surface.json` — discovered `ipcMain.handle`,
  `ipcRenderer.invoke`, and renderer event channels with file/line references.
- `npm run perf:vault` — synthetic Vault index benchmark for release notes and
  scale regression checks.

## What Reviewers Should Check

For every IPC channel:

- Does the handler validate Vault paths in main?
- Does external file access require a `FileAccessGrant`?
- Does the preload API expose the smallest useful shape?
- Does the handler avoid returning secrets, absolute paths, or note bodies
  unless the UI explicitly needs them?
- Is there a regression test for path traversal, sender/purpose mismatch, or
  redaction when the channel is security-sensitive?

For every dependency change:

- Is the package needed at runtime or only development time?
- Does `npm audit` and `npm audit --omit=dev` remain at 0 known
  vulnerabilities?
- Does the license check pass?
- Is the SBOM regenerated for release evidence?

## Current Security Invariants

- The renderer never reads decrypted API keys.
- External PDF/BibTeX/PDF-to-Markdown imports consume one-use picker grants.
- `app-file://` and `plugin-file://` are scoped before disk reads.
- Diagnostics are local-only and redacted.
- Telemetry and Sentry are opt-in.
- Release artifacts are smoke-tested and checksum-verified.

## External Audit Packet

Before asking for an external review, attach or point auditors to:

- [threat-model.md](threat-model.md)
- [operations.md](operations.md)
- [security/ipc-surface.json](../security/ipc-surface.json), generated by CI
- [security/sbom.cdx.json](../security/sbom.cdx.json), generated by CI
- Latest release checksums
- Test coverage report
- [external-audit-readiness.md](external-audit-readiness.md)
- [performance.md](performance.md) and the latest `npm run perf:vault` output

Sensitive user Vault data is not required for the audit packet.
